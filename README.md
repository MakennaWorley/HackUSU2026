# GET IT DONE With Griff! 🦅

A Chrome-based browser extension that helps you stay focused by implementing customizable focus intervals (30/60/90 minutes) with an interactive griffin shimeji mascot that enforces discipline on distracting websites.

## Features

- **Customizable Focus Intervals**: Choose between 30, 60, or 90-minute focus sessions
- **Griffin Shimeji Mascot**: An interactive animated griffin appears and interacts with you throughout your session
- **Blacklist Management**: Define which websites distract you and blacklist them
- **Automatic Site Closing**: After your focus interval expires, the griffin will force-close any blacklisted websites if they're still open
- **Smart Interaction**: The griffin animates and provides visual feedback as your focus session progresses

## How It Works

1. **Start a Session**: Choose your preferred focus interval (30, 60, or 90 minutes) from the extension popup
2. **Stay Focused**: The griffin watches over you as the timer counts down
3. **Enforce Discipline**: When your time is up, any open blacklisted websites are automatically closed
4. **Interact with the Shimeji**: The griffin mascot moves around your screen, adding a fun element to your focus session

## Installation

1. Download or clone this repository
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable "Developer mode" in the top right corner
4. Click "Load unpacked" and select the project folder
5. The extension will appear in your Chrome toolbar

## Configuration

Configure your focus intervals and blacklisted websites:
- Open the extension options/settings
- Set your preferred interval duration
- Add websites to the blacklist that tend to distract you
- Customize the griffin's behavior (optional)

## Tech Stack

- **Frontend**: TypeScript, HTML, CSS
- **Backend**: Chrome Extension API
